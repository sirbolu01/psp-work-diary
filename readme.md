Project Overview

MollyLimpets is a web application that allows users to create and manage playground limpet collections, track item variants, and generate customer-facing URLs. The system consists of a frontend SvelteKit application, a backend .NET 6 Web API, and a MySQL database for dynamic data retrieval and display.

Technology Stack

Frontend: SvelteKit, JavaScript/TypeScript

Backend: ASP.NET Core Web API (C#)

Database: MySQL

Development Tools: Visual Studio, MySQL Workbench, GitHub, Vercel for hosting

Functional Requirements (FRs)

Add new playground items with attributes (name, colour, variant)

Create and manage playground collections

Generate customer-facing URLs for collections

Fetch data from the backend API for frontend display

Update item images and variants

Verify database connectivity and API responses

Non-Functional Requirements (NFRs)

Fast system response for all data retrieval (≤ 2 seconds)

Accessible and responsive design for desktop and mobile devices

Secure backend API with authentication for administrative and customer roles

Maintain database integrity and support concurrent updates

Ensure usability, maintainability, and scalability for future extensions
