# Sprint 1

During the sprint week, my focus shifted from preparation and learning into active integration, testing, and issue resolution. Each day began with discussions with my teammates to review progress, identify blockers, and ensure that everyone was working toward the same sprint goals. I worked closely with the team to confirm that we were aligned on configuration decisions and that the backend was set up consistently across development environments.

A key responsibility during the sprint was validating the backend API’s connection to the MySQL database and ensuring that this data could be successfully consumed by the frontend application. I regularly ran the backend locally to verify database credentials, ports, and environment-specific settings. When issues occurred, such as failed API responses or connection errors, I communicated findings with my teammates and worked collaboratively to resolve them before they affected overall progress.

As frontend–backend integration progressed, I supported troubleshooting when API calls failed from the frontend. This involved checking request URLs, confirming that ports and routes matched the running backend, and using browser developer tools to inspect network requests and responses. Many issues were caused by small configuration mismatches, which were resolved by coordinating with the team to standardise configuration values and ensure the backend was correctly configured for both local and hosted environments.

Throughout the sprint week, I documented daily activities, challenges, and resolutions in the GitHub work diary. I also assisted teammates encountering setup or configuration issues by helping them verify database connections and backend settings. This collaborative approach reduced repeated errors and ensured that the team maintained steady progress.

By the end of the sprint week, these actions contributed to achieving a stable, working end-to-end system that could be demonstrated to the client, with reliable database connectivity and successful frontend–backend communication.
